加密助手（CryptoAssistant）Windows 安装版

安装
----
1. 双击 CryptoAssistant-<版本>.exe。
2. 安装程序需要管理员权限，默认安装到：
   C:\Program Files\CryptoAssistant
3. 可选择开始菜单快捷方式与桌面快捷方式。

数据位置
--------
安装目录在 Program Files 下不可写，程序会把数据放到：
   %APPDATA%\CryptoAssistant\data
包括密钥、联系人、历史、设置与日志。卸载程序不会删除该目录。

卸载
----
设置 -> 应用 -> 已安装的应用 -> 加密助手 -> 卸载。
卸载只移除程序文件；如需彻底清除数据，请手动删除
   %APPDATA%\CryptoAssistant

便携版
------
如果不想安装，使用 CryptoAssistant-<版本>-win64.zip，
解压后直接运行目录内的 CryptoAssistant.exe；数据保存在 exe 旁的 data 目录。
